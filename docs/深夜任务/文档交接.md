# 两页 PPT 文档交接

本文给 PPT 和书面材料负责人使用。两页分别讲安全信道与 USRP 链路，不要把控制面加密写成 IQ 数据面加密。

## 第 1 页：后量子安全控制与认证

**建议标题：** ML-KEM + 国密双签名安全控制信道

**页首结论：** 系统先认证板端身份并授权任务，再建立可复用的加密控制信道；不具备可信密码后端时拒绝通信。

**主图从左到右：**

```text
Cockpit / 上位机
  -> ML-KEM-768 密钥封装
  -> ML-DSA-65 + SM2 双签名验证握手上下文
  -> HKDF 派生会话密钥
  -> SM4-GCM 加密控制消息并绑定 AAD
  -> 飞腾派准入、状态与任务控制
```

**图下保留三点：**

1. **抗量子密钥协商：** ML-KEM-768 防范“先截获、后解密”；Tongsuo 不可用时回退到可信 liboqs，两者都不可用则停止建链。
2. **双重身份认证：** ML-DSA 提供后量子签名，SM2 满足国密合规；演示默认 `DUAL_REQUIRED`，两种签名必须同时通过。
3. **完整性与保密性：** SM4-GCM 同时校验密文和 AAD，篡改任务号、形状或认证标签都会导致解密失败。

**建议指标卡：** 一次冷握手约 `0.3-0.8 s`，本轮实测 `752 ms`；后续任务复用常驻会话，不按图片重复握手。控制台提供 S-FIT-01～07 上位机负向自检；FIT-01～03 为 OpenAMP 真机注入。

**30 秒讲稿：** “加密和认证是两项独立能力。ML-KEM 负责协商密钥，SM4-GCM 负责控制消息的保密与完整性；ML-DSA 和 SM2 负责确认对端身份。默认配置把两项同时打开，并复用会话摊薄握手开销。USRP 模式下它保护准入和控制面，不宣称模拟 IQ 已做 AEAD 加密。”

## 第 2 页：USRP IQ 直传语义链路

**建议标题：** 面向连续语义特征的 USRP IQ 直传

**页首结论：** Deep JSCC latent 允许小幅模拟误差，因此可直接映射为复数 I/Q 符号，省去 QPSK 字节成帧与逐块解包，同时保留同步、质量门限和重传。

**主图从左到右：**

```text
原图 -> Deep JSCC Encoder -> 1x32x32x32 latent
     -> RMS 归一化 / I-Q 配对 / 导频 / RRC
     -> 上位机 USRP TX ~~ 真实无线信道 ~~ 板端 USRP RX
     -> 匹配滤波 / 同步 / CFO、增益和相位恢复
     -> 质量门限 + ARQ -> handwritten TVM + big.LITTLE -> 重建图
```

**图下保留三点：**

1. **真实数据面：** 默认中心频率 `500 MHz`、采样率 `5 Msps`、TX/RX gain `25/15`；射频数据不经过 Tailscale。
2. **可靠性闭环：** TX/RX 与 decode worker 常驻；长任务按 30 张分段，单图最多 12 轮 ARQ，失败子集再补传 2 轮。
3. **稳定重建：** 门限检查 sync、pilot gain、EVM 和 SNR；板端使用 handwritten TVM artifact，大核 2 推理，小核 0、1 预取与保存。

**建议指标卡：** 2026-07-18 回归中，300 张全部成功；空口中位数 `9.63 ms/帧`，传输/解码中位数 `248.49 ms`，TVM 核心中位数 `241.79 ms`。QPSK 20 张传输中位数 `4.98 s/张`，历史最好值约 `2.96 s/张`。整批墙钟时间必须单列，不能把 `241.79 ms` 写成 USRP 端到端时延。

**30 秒讲稿：** “Encoder 输出连续 latent，我们把相邻实数作为 I、Q 分量发送。接收端通过导频完成同步、频偏和复增益恢复，再由质量门限与 ARQ 处理偶发坏帧。相比 QPSK，主链路减少字节级调制、CRC 分块和解包开销；相比裸模拟传输，又保留了可检测、可重试、可审计的可靠性闭环。”

## 禁止混用的表述

- 不写“USRP IQ payload 已由 ML-KEM + SM4 加密”；正确说法是“安全信道认证设备并保护准入与控制面”。
- 不写“Encoder 输出可直接接天线”；中间仍有归一化、导频、RRC、同步和信道恢复。
- 不把 TVM 核心时间、空口时间和整批端到端时间合并成一个指标。
- 不把 S-FIT 上位机自检写成板端真机故障注入。
