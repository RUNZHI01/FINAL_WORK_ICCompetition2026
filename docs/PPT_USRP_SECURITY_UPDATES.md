## 第 20 页：USRP IQ 直传链路

用当前链路替换旧的 `wire blob + QPSK + CRC32` 内容。

```text
原图
 -> Deep JSCC encoder
 -> float32 latent
 -> RMS 归一化、I/Q 配对
 -> 同步序列/导频、RRC 成形、sc16
 -> USRP-2922 射频链路
 -> 定时、CFO、复增益/相位恢复
 -> noisy latent
 -> handwritten TVM + big.LITTLE
 -> 重建图
```

右侧只放三组信息：

- **无线参数：** `500 MHz`，`5 Msps`，TX/RX gain `25/15`。
- **可靠性：** 常驻 TX/RX；30 张分段；ARQ12；失败子集最多补传 2 轮；同步、EVM、SNR 门限验收。
- **实测：** 严格 300 张 `300/300` accepted、fallback `0`；传输/解包 median `411.59 ms`、p95 `3423.45 ms`；板端 TVM median `245.42 ms`。

页脚注明：`245.42 ms` 是 TVM 核心推理，不是 USRP 单张端到端时间。名义空口约 `9.58 ms/帧`，实际耗时主要受同步门限和重传长尾影响。
